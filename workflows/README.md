# Workflows

Reusable workflow runbooks for the fabric. Each file documents a repeatable
process end-to-end. These are portable across systems — adapt the concrete
tooling, keep the process.

- [`ci-cd.md`](ci-cd.md) — CI/CD policy and gates.
- [`issue-handler.md`](issue-handler.md) — issue automation flow, roles, loop prevention, status protocol.
- [`pr-best-practices.md`](pr-best-practices.md) — PR workflow rules.
- [`monitoring.md`](monitoring.md) — status labels and the single status comment.
- [`backup-restore.md`](backup-restore.md) — Gitea data backup and disaster recovery.
- [`e2e-poc-validation.md`](e2e-poc-validation.md) — end-to-end PoC validation.
- [`python-to-go-migration.md`](python-to-go-migration.md) — migration runbook.
