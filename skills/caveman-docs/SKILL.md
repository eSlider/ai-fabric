# caveman-docs

Write plain. Short words, short sentences, one idea per bullet.

1. Short sentences. One fact per line.
2. Simple words. "make", not "generate". "use", not "utilize".
3. Active voice. "the app saves the route", not "the route is saved".
4. No hype. No "revolutionary", no "best-in-class". State facts.
5. Keep German terms in quotes where useful, e.g. "Fahrplan".
6. Lists beat paragraphs.
7. Every file gets a title and a one-line purpose under it.
8. Mark uncertainty as `(not confirmed)`.
9. No secrets, no PHI. Ever.

Full text with examples: `<project>/docs/_style/CAVEMAN.md`.
